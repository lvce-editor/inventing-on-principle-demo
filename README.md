# Inventing on Principle: Live Tree

A small, playful demo of Bret Victor's principle that creators should have an immediate connection to what they create. Change the tiny program on the left and its tree redraws on the right—without saving, pressing Run, or leaving the thought.

This is an independent homage built with `@lvce-editor/server`, not a recreation of Victor's original environment. It uses LVCE's native editor and HTML preview to focus on the essential prerequisite: a tight edit/feedback loop. Numeric scrubbing and code-to-output provenance remain explicit future fidelity targets.

## Try it

The static LVCE build is published at [lvce-editor.github.io/inventing-on-principle-demo](https://lvce-editor.github.io/inventing-on-principle-demo/). Press F1 there and run the demo command below.

To run it inside LVCE, use Node 24:

```sh
npm ci
npm run dev
```

Open <http://localhost:3000>, press F1, then run:

> Inventing on Principle: Open Live Tree Demo

The command writes a small HTML program into the current workspace, opens it in LVCE's text editor, and shows LVCE's native preview on the right. Start with these edits:

| Parameter     | Try                       | What changes                       |
| ------------- | ------------------------- | ---------------------------------- |
| `depth`       | `8` → `10`                | A 511-branch tree becomes 2,047    |
| `spread`      | `0.48` → `0.7`            | The crown opens outward            |
| `lengthRatio` | `0.73` → `0.8`            | Branches become long and luxuriant |
| `wind`        | `0.025` → `0.12`          | The whole tree leans               |
| `leafColor`   | `'#718355'` → `'#c46f3a'` | Summer turns to autumn             |

The status below the Canvas is generated by the same edited script, making it easy to see that LVCE has rerun the program rather than merely restyled old markup.

## How it works

The extension contributes `inventingOnPrinciple.openLiveTree`. It uses the extension API to create `inventing-on-principle.html`, opens that URI in the main editor, and executes `Layout.showPreview` for the same URI. Everything visible in the editing loop is provided by LVCE.

The preview executes the document script in LVCE's preview sandbox. Canvas drawing happens through a transferred `OffscreenCanvas`; the sandbox serializes the resulting document, and LVCE's virtual DOM reconciles it into the preview. Editor changes rebuild that sandbox document and rerun its scripts before the preview is patched.

## Static site and GitHub Pages

```sh
npm run build:site
```

This exports a complete static LVCE build into `.tmp/static`. CI builds and validates the editor on every pull request. Successful `main` and manual workflows upload that same generated editor and deploy it through GitHub Pages.

## Research

The original tree sequence runs roughly from 3:20 to 9:35 in [_Inventing on Principle_](https://vimeo.com/906418692). It combines immediate redraw, literal scrubbing, discovery through continuous feedback, and bidirectional source/output navigation. See the [research note](docs/research.md) for a timestamped breakdown and the explicit v1 boundary.

Victor's broader explanation is also worth reading in [_Learnable Programming_](https://worrydream.com/LearnableProgramming/): instant updates are a prerequisite for a responsive creative medium, not the whole interaction design.
